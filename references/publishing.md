# Publishing

Use this when the user asks for Xiaohongshu publishing help, account setup, titles, captions, hashtags, or series planning.

## Post Package

For a ready-to-publish post, provide:

- cover title
- 3-5 post title options
- short caption
- hashtags
- comment prompt
- next-post suggestion

## Title Patterns

Use concise, emotionally sticky titles:

- 一张图读懂 XXX
- 长大后才读懂 XXX
- XXX 真的后劲太大了
- 原来 XXX 才是隐藏主角
- 小时候看热闹，长大后看人心
- XXX 的关系终于理清了
- 被低估的 XXX
- 这才是 XXX 最狠的地方
- 看完突然懂了 XXX

## Caption Structure

Use this structure:

```text
小时候看《XXX》，只记得……
长大后再看，才发现……
所以这张图把 XXX 整理成了：
1. ...
2. ...
3. ...
建议收藏，下一期想看谁？
```

Keep the caption warm, conversational, and easy to comment on.

## Interaction Hooks

Use one per post:

- 你最喜欢谁？
- 哪句话后劲最大？
- 你小时候最误解谁？
- 下一期想看谁？
- 这张关系图你看懂了吗？
- 你觉得谁才是隐藏主角？

## Account Bio Direction

Use a soft, clear positioning:

```text
把古典文学做成治愈系国风手账
一张图读懂人物、关系和后劲
四大名著｜古诗词｜东方美学
```

Shorter version:

```text
用国风手账读懂古典文学
四大名著｜人物关系｜东方美学
```
