# Templates

Choose one template before writing the final prompt. If the user does not specify a format, default to 3:4 vertical Xiaohongshu cover.

## Template A: Overview Cover

Use for large topics, books, eras, schools, or "one image to understand X".

Structure:

- top: large brush-calligraphy title
- title side: red seal and 2-4 collection tags
- center: clustered key figures, events, or symbols
- left/right: sticky notes, arrows, quick explanations
- bottom: timeline, map, faction strip, chapter tags, or summary row

Required prompt ingredients:

- topic title
- 4-8 core elements
- 3-6 annotation phrases
- map/timeline/relationship cue if relevant
- visual promise such as "一张图读懂"

Best for:

- 三国演义
- 红楼梦
- 水浒传
- 西游记
- 唐诗宋词
- 朝代总览

## Template B: Character Cover

Use for a single person, historical figure, poet, or literary character.

Structure:

- top: large brush-calligraphy name
- below: 1-2 identity subtitles
- center: character sticker illustration, half-body or three-quarter view
- side notes: events, traits, symbols, famous lines
- bottom: emotional interpretation

Required prompt ingredients:

- name
- identity subtitles
- facial temperament
- clothing color and symbolic object
- 3-5 classic events or keywords
- 3-5 Xiaohongshu annotations

Best for:

- 曹操
- 刘备
- 孙权
- 诸葛亮
- 林黛玉
- 薛宝钗
- 苏轼
- 李白

## Template C: Relationship Map

Use for complex groups, factions, family trees, emotional relationships, and plot networks.

Structure:

- center: relationship web, faction map, or family tree
- around: character stickers or profile cards
- arrows: alliances, conflicts, kinship, romance, mentorship
- bottom: legend or simplified reading guide

Required prompt ingredients:

- group categories
- arrow meanings
- color grouping
- 5-10 major nodes
- visual clarity instruction

Best for:

- 红楼梦人物关系
- 三国阵营
- 水浒 108 将分组
- 朝代人物关系

## Template D: Quote Or Reflection Card

Use for poetry, literary quotes, emotional healing posts, and philosophical reflections.

Structure:

- center: large quote or short sentence
- background: old paper with generous empty space
- decoration: one symbolic object or scene
- annotation: 1-3 small reflections

Required prompt ingredients:

- quote or sentence
- mood
- season/time/object
- restrained collage elements
- strong empty-space instruction

Best for:

- 古诗词
- 孤独感
- 女性成长
- 人生后劲
- 文学金句

## Template E: Account Visual

Use for avatar, banner, creator IP, or profile visual.

Structure:

- clear central subject
- simple scrapbook background
- fewer text elements
- stable brand colors
- suitable crop requirement

For avatar:

- face or symbol occupies 55-65% of frame
- circular crop safe
- background not too busy
- high recognizability at small size

Best for:

- 小红书头像
- 账号主页视觉
- 博主 IP 形象
- 系列封面统一视觉
