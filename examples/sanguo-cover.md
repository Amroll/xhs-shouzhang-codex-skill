# Example: 三国演义总览封面

```text
主题：
《三国演义》小红书知识封面

画幅：
3:4 竖版

核心风格：
治愈系国风手账拼贴风，Scrapbook Collage，小红书高收藏知识可视化，清透米白奶油纸背景，干净手账纸纹理，柔和裁纸边缘，和纸胶带，便利贴，手写批注，轻水彩插画，细腻彩铅笔触。

标题文字：
清晰国风标题「三国演义」，柔和墨色标题，旁边加入浅珊瑚小印记。

副标题/标签：
「一张图读懂三国」
「建议收藏」
「四大名著」
「人物关系终于理清了」

主体画面：
刘备、关羽、张飞、诸葛亮、曹操、孙权、周瑜以国风人物贴纸形式围绕浅色地图贴纸排布，形成三国阵营关系感。

经典元素：
桃园结义、三顾茅庐、草船借箭、赤壁之战、浅色地图贴纸、战旗小图标、羽毛扇、淡墨线条山水。

小红书批注：
“小时候根本没看懂”
“这里封神”
“诸葛亮真的太强了”
“看完后劲太大了”

颜色：
米白、浅卡其、豆沙红、墨黑、竹绿色、淡金色。

光线与质感：
柔和暖光，真实纸张阴影，层次丰富但不杂乱，像认真整理过的文学手账。

情绪氛围：
国风、治愈、知识感、收藏感、小清新、高级文艺。

构图要求：
视觉中心明确，标题强识别，信息密度高但舒服，适合小红书封面点击与收藏。

负面规则：
no realistic photo, no 3D render, no CGI, no modern clothing, no dark horror style, no movie poster, no game splash art, no messy composition, no unreadable text
```
